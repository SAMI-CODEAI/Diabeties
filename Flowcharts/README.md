# GlucoVision Flowcharts

This folder contains simplified flowcharts for the project report. Each flowchart is designed to fit on one or half page.

## Flowchart List

1. **System Architecture** - Overall system components and data flow
2. **Model Training Pipeline** - Steps from dataset to trained model
3. **Application Workflow** - User journey through the web application
4. **Data Preprocessing** - Data cleaning and preparation process
5. **XGBoost Architecture** - Model structure and prediction mechanism
6. **XAI Integration** - Explainable AI implementation workflow
7. **Prediction Workflow** - Single prediction end-to-end process

## Usage

These Mermaid diagrams can be:
- Rendered in Markdown viewers (VS Code, GitHub, etc.)
- Converted to images using Mermaid CLI or online tools
- Directly included in LaTeX/Word documents using mermaid packages
- Used in presentations

## Rendering Tips

For best results in reports:
- Use landscape orientation for wider diagrams
- Export as PNG/SVG with 300 DPI minimum
- Maintain color scheme for consistency
